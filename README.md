# ArkStallCutter

用于简中服明日方舟录屏的自动剪辑工具，提供中文桌面界面和命令行。当前版本：1.5。

## 功能

- 删除中央显示 `PAUSE` 的暂停画面。
- `1X` 画面加速 2 倍，`2X` 保持原速，选中干员的 0.2 倍子弹时间加速 10 倍。
- 清理短选中操作及视角回正过渡；按余晃情况再省略最多 1～2 帧，优先保证观看连贯。
- 根据画面高度和相对区域识别 UI，适配不同分辨率、超宽录屏和异形屏安全区。
- 保持音频变速音高，支持短尾音和切点淡化，尽量减少音效截断。
- 可调整画质、帧率、编码速度、镜头清理和声音设置；复用识别报告可加快重复导出。

## Windows 使用

1. 下载并完整解压代码，保留 `arknights_cutter/templates` 文件夹。
2. 安装 [Python 3.10 或更高版本](https://www.python.org/downloads/)，启用 **Add Python to PATH** 并保留 **Tcl/Tk** 组件。
3. 准备 [FFmpeg 和 FFprobe](https://ffmpeg.org/download.html)：加入 PATH，或将两个程序放到工具目录下的 `bin` 文件夹，也可在界面高级设置中指定位置。
4. 双击 `启动界面.cmd`，选择输入视频、输出位置，开始剪辑。视频也可拖到启动器上。

首次启动会自动创建 `.venv` 并联网安装识别依赖；以后直接复用。Python 和 FFmpeg 需要预先安装。
默认输出 `原名.edited.mp4` 和剪辑报告，原视频不修改。配置可在界面保存供下次使用。

## 常用设置

- **镜头清理方式**：默认连贯优先，会省略少量操作过程；关闭则保留选中操作并按 10 倍速处理。
- **镜头恢复检查窗口**：寻找回正位置的最长源视频时间，默认 1000 毫秒，并非固定裁掉这么长。
- **恢复后多去掉几帧**：默认自动，最多 2 帧；可设为 1 帧或关闭。按输出帧率限制时间，60 fps 最多约 33.3 毫秒。
- **声音处理**：默认保留 120 毫秒尾音、8 毫秒切点淡化；声音重叠时可改为平滑切点。

## 命令行

```powershell
python -m pip install -r requirements.txt
python arkcut.py "video.mp4" -o "edited.mp4"
python arkcut.py "video.mp4" -o "edited.mp4" --reuse-analysis --camera-settle-frames 1
python arkcut.py --help
```

也可把视频拖到 `启动剪辑.cmd`，按默认设置处理。特殊黑边或裁剪可通过 `config.example.json` 调整识别区域。

识别依赖简中战斗 UI；严重遮挡、很低分辨率或 UI 改版可能需要调整配置。游戏特效自身的震屏不会被消除。
音轨已混合音乐、语音和音效，无法单独恢复某一种声音。处理需要重新编码，速度取决于视频长度和电脑性能。
